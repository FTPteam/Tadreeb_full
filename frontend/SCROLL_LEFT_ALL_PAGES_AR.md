# إصلاح موضع السكرول العمودي في كل صفحات Tadreeb

## السبب
كان `index.html` يبدأ بـ `<html lang="en">` دون `dir="rtl"`؛ بينما اتجاه النصوص يُضبط من مكوّنات React وCSS فقط. هذا التباين قد يجعل موضع شريط التمرير العمودي في مستند المتصفح غير متسق مع اتجاه واجهات RTL.

## التعديل
- `index.html`: تعيين `lang="ar" dir="rtl"` على عنصر html؛ وتصحيح مسار أيقونة الموقع.
- `src/index.css`: توحيد اتجاه المستند وصفحات المحتوى ومناطق التمرير العمودي إلى RTL.
- لم نغير السايدبار، ولا ترتيب البطاقات أو مكوّنات الصفحات، ولا نخفي السكرول، ولا نغير عرض التواريخ والأكواد LTR.

## التركيب
انسخ الملفين من حزمة الإصلاح إلى نفس المسارات داخل مشروعك، ثم شغّل:

```powershell
npm run build
npm run dev
```

أعد تحميل المتصفح بالضغط على Ctrl+Shift+R. اختبر السجل اليومي للطالب والإدارة، صفحة الحضور، وصفحات جهة التدريب، والجداول ذات التمرير الأفقي.

## ملاحظة
الموضع الفعلي لشريط التمرير الأصلي يخضع أيضًا لمحرك المتصفح ونظام التشغيل وإعداداته. وضع RTL على عنصر `html` هو الحل القياسي على مستوى المستند، أما الشريط الذي ينشئه نظام التشغيل خارج المستند فلا يمكن التحكم بمكانه برمجيًا في جميع المتصفحات. اختبر خصوصًا على Chrome/Edge في Windows.
