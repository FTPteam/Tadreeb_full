# تركيب نسخة مراجعة Tadreeb

**اختر أحد الخيارين:**

- ZIP كامل: فكّه في مجلد جديد للمقارنة والتجربة.
- ZIP تصحيحات فقط: انسخ الملفات المعدلة إلى المسارات المطابقة داخل مشروعك الحالي مع نسخة احتياطية.

نفّذ:

```powershell
npm ci
npm run build
npm run dev
```

جرّب الحضور والتسجيل في **نفس المتصفح** لأن البيانات ما زالت تجريبية باستخدام localStorage. في بوابة جهة التدريب افتح «الحضور والسجلات» وحدد تاريخًا وسجّل حضورًا للطالب. تحقق من ظهور سجل اليوم نفسه لدى الطالب وفي «متابعة التدريب» لدى الإدارة، ثم عدّل ساعات اليوم وأعد التحقق.

**مهم:** لأن النسخة السابقة كانت تحتوي على ساعات افتراضية بدون سجلات حضور، سيُحسب المجموع من أيام الحضور المسجلة فعليًا بدءًا من أول يوم يتم تسجيله. هذا سلوك مقصود لمنع إبقاء الأرقام النموذجية كأنها ساعات معتمدة، لكنه ليس ترحيلًا لبيانات إنتاج. إن كان لديك بيانات حقيقية على المتصفح، لا تستبدل النسخة قبل عمل نسخة احتياطية منها.

لم أتمكن من تنفيذ Vite Build كامل في بيئة الإنشاء بسبب عدم وجود جميع حزم npm في التخزين المحلي؛ فحصت صياغة JavaScript/JSX والروابط والاستيرادات الثابتة. راجع `SYSTEM_REVIEW_AR.md` قبل اتخاذ قرار النشر.
