# Tadreeb — توحيد الفوتر + نطاق الهندسة وتكنولوجيا المعلومات

هذه الحزمة مدمجة على أساس ملف `frontend.zip` الذي رفعه صاحب المشروع، وتتضمن **جميع تعديلات المرحلة السابقة** الموجودة في `tadreeb_engineering_it_phase1.zip`، بالإضافة إلى تعديل الفوتر الموحد في البوابات الثلاث.

## الملفات الأساسية الجديدة/المعدلة
- `src/components/shared/AcademicFooter.jsx`: فوتر مشترك لجميع الأدوار، مع مودالي دليل التدريب والدعم الفني والأكاديمي يعملان من كل بوابة. يستخدم Portal لتجنب ظهور overlay فوق المودال.
- `src/components/training-provider/ProviderFooter.jsx`: غلاف صغير للمكوّن المشترك، بدون تغيير طريقة استخدام `ProviderFooter` في صفحات جهة التدريب.
- `src/components/admin/AdminPageLayout.jsx`: الفوتر المشترك لجميع الصفحات التي تستخدم تخطيط الإدارة.
- صفحات الطالب والإدارة: استبدال التذييلات النصية أو غير الفعالة بالمكوّن المشترك، وإضافته إلى الصفحات التي لم يكن فيها فوتر، مع حذف مكونات `Footer` المحلية المتكررة.
- صفحات تسجيل الدخول الثلاث للطالب، و`AdminAuthLayout.jsx` و`training-provider/AuthLayout.jsx`: فوتر مصغر مدمج بنفس وظائف الدليل والدعم.
- التعديلات السابقة لقوائم التخصصات وبيانات الفرص ضمن نطاق الهندسة وتكنولوجيا المعلومات، مع تصحيح فرص الداشبورد ونموذج تقديم الطالب كذلك.

## اختيار الدليل حسب الدور
- الطالب: «دليل الطالب للتدريب الميداني».
- الإدارة/المشرف الأكاديمي: «دليل المشرف الأكاديمي للتدريب الميداني».
- جهة التدريب: «دليل الجهة للتدريب الميداني».

## تعليمات التثبيت
1. احتفظ بنسخة احتياطية من المشروع الحالي.
2. عند استخدام حزمة التعديلات `tadreeb_unified_footer_and_scope_patch.zip`: انسخ محتويات `src/` فوق `src/` الموجودة في مشروعك، مع الحفاظ على المسارات.
3. أو استخدم `tadreeb_frontend_unified_source.zip` كمصدر مشروع كامل **من دون** `node_modules` و`.git`؛ ثم نفّذ `npm ci` وبعدها `npm run build`.
4. لا توجد Routes جديدة ولا حاجة لتعديل `App.jsx`.
5. تحقق من النوافذ في صفحات الطالب والإدارة وجهة التدريب، على الكمبيوتر والجوال.

## ملاحظات مهمة قبل التشغيل الجامعي الفعلي
- **أرقام التواصل في الفوتر من النسخة الأصلية**، ويجب التأكد منها رسميًا قبل إطلاق الجامعة.
- تحميل ملف دليل PDF ما زال **معطّلًا عمدًا** لأن المستخدم لم يرفع ملف الجامعة المعتمد. المودال نفسه يعمل ويمكن إغلاقه بزر Escape أو بالضغط خارج النافذة.
- قائمة التخصصات مستمدة من الكود المتاح، ويجب اعتماد مسمياتها وأكوادها رسميًا من القسم.
- مكوّن الفوتر والتعديلات الحالية لا يعنيان اكتمال ربط البيانات أو الصلاحيات أو API بين البوابات؛ هذا عمل منفصل لاحق.
- بيانات `localStorage` في كل متصفح لا تتزامن عبر الأجهزة.
- تسجيل الدخول تجريبي في الوضع الحالي، وليس مصادقة إنتاجية.

## التحقق المنفذ
- تحليل نحو 111 ملف JavaScript/JSX باستخدام TypeScript Parser: **صفر أخطاء تركيبية**.
- فحص المراجع النسبية للـ imports: **صفر ملفات مفقودة**.
- محاولة `vite build`: **لم تكتمل** لأن حزمة `node_modules` المرفوعة بنيت على Windows، وتفتقد `@rolldown/binding-linux-x64-gnu` الذي يحتاجه Vite في بيئة Linux. يلزم `npm ci` على نظام التشغيل الحالي للتأكد من Build فعلي.
- لم يجرِ اختبار بصري تلقائي لكل صفحة أو اختبار تكامل شامل.
